# Multi-Tenant E-Commerce Platform

Multi-tenant e-commerce SaaS built with React, Node.js, Express, and MongoDB.

## Setup

### Backend

```bash
cd backend
npm install
```

Create a `.env` file (see `.env` in the repo for reference).

```bash
npm run dev
```

Runs on `http://localhost:5000`

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Runs on `http://localhost:5173`

## Tech Stack

- **Frontend:** React, Vite, Tailwind CSS, Redux Toolkit
- **Backend:** Express, MongoDB, Mongoose
- **Auth:** JWT + bcrypt (coming soon)
